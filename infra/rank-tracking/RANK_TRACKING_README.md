# Rank-tracking инфраструктура для kredato.com

Факт-отчёт и рекомендации по точному замеру позиций в Google и Яндекс.

---

## Что создано

| Артефакт | Путь | Статус |
|----------|------|--------|
| Скрипт GSC (read-only) | `infra/rank-tracking/gsc_rank_tracker.py` | Готов к запуску после подключения ключа |
| Скрипт Яндекс (read-only) | `infra/rank-tracking/yandex_rank_tracker.py` | Готов к запуску после подключения токена |
| Инструкция по ключам | `infra/rank-tracking/API_KEYS_SETUP.md` | Готова |
| База ключевых слов | `reports/keywords/2026-08-05.json` | 14 запросов (commercial + informational) |

---

## Что можно сделать прямо сейчас (без ключей пользователя)

1. **Инспекция ключевых слов** — база `reports/keywords/2026-08-05.json` уже содержит 14 коммерческих и информационных запросов. Можно расширять этот список (см. ниже).
2. **Подготовка окружения** — установка зависимостей:
   ```bash
   pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib
   ```
3. **Альтернативный метод без API (ручной)** — открыть Google в incognito и проверить позиции вручную. Пригодно для 1-2 разовых проверок, не для регулярного отслеживания.
4. **Анализ существующих отчётов** — в `reports/` уже есть SEO-аудит (`seo-audit-kredato-2026-08-13.md`) с базовой диагностикой индексирования.

## Что требует ключей пользователя

### Google Search Console API (обязательно)

Для запуска `gsc_rank_tracker.py` нужен:
- Service Account JSON-ключ из Google Cloud Console.
- Доступ к ресурсу `https://kredato.com/` в GSC (добавить email SA как Reader).

Скрипт возвращает JSON с полями: `query`, `position`, `impressions`, `clicks`, `ctr` за последние 30 дней.

### Yandex.Webmaster API v4 (обязательно)

Для запуска `yandex_rank_tracker.py` нужен:
- OAuth-токен Яндекс с scope `webmaster:read`.
- Аккаунт, владеющий `https://kredato.com` в Яндекс.Вебмастере.

Скрипт возвращает JSON с полями: `query`, `avg_position`. Источники: `popular-queries` (все время) + `history` (последние 30 дней).

## Рекомендации по альтернативам

### 1. SerpApi (SERP scraping)

**Плюсы:**
- Не требует доступа к GSC/Вебмастеру.
- Возвращает реальные позиции из выдачи Google и Яндекс прямо сейчас.
- Есть бесплатный тариф (100 запросов/мес).

**Минусы:**
- Позиции могут плавать (персонализация, гео, язык).
- Нет данных об impressions/clicks из официальных источников.
- Зависимость от внешнего сервиса.

**Когда использовать:** для разовых проверок или как бэкап, если сайт ещё не подключён к GSC/Вебмастеру.

### 2. Residential proxy + headless-скрапер

**Плюсы:**
- Полный контроль над запросами.
- Можно эмулировать любой гео/устройство.

**Минусы:**
- Яндекс активно блочит ботов; требуется резидентный прокси с пулом IP (например Bright Data, IPRoyal).
- Юридические риски: обходrate-limit Яндекса может нарушать ToS.
- Сложнее в поддержке, чем официальные API.

**Когда использовать:** для конкурентной разведки (отслеживание позиций конкурентов), если они не раскрывают свои GSC/Вебмастер.

### 3. Гибридный подход (рекомендуемый)

- **Постоянный мониторинг kredato.com** — через GSC API + Яндекс API (официальные, точные, бесплатные).
- **Конкурентный снэпшот раз в неделю** — через SerpApi или резидентный прокси для 10-20 ядерных запросов.

## Дальнейшие шаги

1. Пользователь получает ключи по инструкции в `API_KEYS_SETUP.md`.
2. Сохраняет ключи в `C:\Users\User\.secrets\` (не в репозитории).
3. Запускает скрипты через env vars.
4. Для расширения keyword-базы — доработать `reports/keywords/` (добавить запросы из Wordstat/Яндекс.Директ, если появятся API-ключи туда).
