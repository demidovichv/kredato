# Дорожная карта операционной системы Kredato + DemidArt

> Создано: 2026-08-05. Каждый агент — автономный, по расписанию, артефакты только внутри проекта.

## 1. Агенты Kredato (`F:\Email_Marketing_Repository\`)

| Агент | Задача | Расписание | Артефакты | Канал |
|---|---|---|---|---|
| **Монитор здоровья** | Доступность сайта, 5xx, тикер, форма подписки, `/api/confirm`, PDF | Каждые 15 мин | `reports/health/YYYY-MM-DD.md` | Telegram при падении |
| **Сборщик ключей** | Вордстат/Яндекс Автодополнение → портфель НЧ-ключей | Раз в 3 дня | `reports/keywords/YYYY-MM-DD.md` | В чат на утверждение |
| **Агент-писатель** | Статьи по утверждённому портфелю | После approve ключей | `site/.../index.html` + PR | В чат на approve |
| **Монитор контента** | Битые ссылки, дубли, пустые страницы | Раз в день | `reports/content/YYYY-MM-DD.md` | Telegram |
| **Агент соцсетей** | Посты/креативы под статьи | После публикации статьи | `reports/social/YYYY-MM-DD.md` + тексты | В чат на approve |
| **Деплой-агент** | Только после явного approve пользователя | По триггеру | Cloudflare Pages | — |

## 2. Агенты DemidArt (`F:\demid-art\`)

| Агент | Задача | Расписание | Артефакты | Канал |
|---|---|---|---|---|
| **Монитор DemidArt** | Доступность, битые ссылки, производительность | Каждые 30 мин | `reports/health/YYYY-MM-DD.md` | Telegram при падении |
| **Агент-дизайнер** | Фоны, карточки работ, герой, адаптив | Раз в неделю / по запросу | `references/design-notes/YYYY-WXX.md` | В чат варианты |
| **Агент превью** | Стиль превью под DemidArt: одна идея, читаемость в малом | После approve дизайна | `references/thumbnails-style-guide.md` | В чат на approve |
| **Агент соцсетей DemidArt** | Посты/Short по готовым работам | После approve превью | `reports/social/YYYY-MM-DD.md` + тексты | В чат на approve |
| **Деплой-агент DemidArt** | Только после явного approve пользователя | По триггеру | Cloudflare Pages | — |

## 3. Правила
1. **Никакой авто-деплой без approve пользователя.** Агенты только готовят.
2. **Никогда не выполняю сразу то, что собрали агенты.** Сначала показываю в чате, обсуждаем, потом внедряю.
3. **Артефакты только внутри проекта:** Kredato → `F:\Email_Marketing_Repository\`, DemidArt → `F:\demid-art\`.
4. **Вордстат:** сборщик ключей обязан показывать источник Яндекс Wordstat, частоту и конкурентность. Без этого — нет ключей.
5. **Соцсети:** посты публикуются только после явного approve пользователя.

## 4. Следующие шаги
1. Запустить Монитор здоровья Kredato — 5 минут.
2. Запустить Сборщик ключей — портфель завтра.
3. Запустить Монитор DemidArt — сразу.
4. После approve дизайна → внедряем фишки/фон DemidArt.
